# 个人中心样式实施计划

**Goal:** 将用户批准的工具类个人中心样式落地为原生 Compose 页面，同步文档并覆盖安装到 P30。

**Architecture:** 保留 AccountEngine、会话与账号操作协议。个人中心拆分为资料头部、分组菜单和二级页面；StarterScreen 继续持有安全确认与微信资料弹窗。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、Material Icons。

**Spec:** 用户批准的 2026-10-29 个人中心参考图：浅灰背景、青绿强调色、白色圆角分组列表、首页/我的双标签。

## 约束与检查重点

- 不重置、退出或注销真实账号，不改后端、数据库、Redis、签名或 applicationId。
- 仅正常微信登录/绑定后出现资料选择，不增加独立微信资料授权入口。
- 待确认操作和隐藏私有资料的保护必须继续生效。
- 长昵称、游客、未连接、系统返回、debug/release 分离均需考虑。
- 帮助提供本地账号说明；反馈/隐私/协议仅在配置真实 HTTPS 地址后打开，未配置明确说明，不能编造已上线服务。
