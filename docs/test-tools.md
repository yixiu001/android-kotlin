# 联调工具与首次安装状态

入口：debug 包“我的 → 开发工具”。本项目 product.properties 已启用 TEST_TOOLS_ENABLED=true；配置缺项时回退 false，新产品应默认关闭。release 强制 false，工具实现仅 src/debug；共享 AccountEngine 桥接同时校验 DEBUG 和开关。

## 当前账号一键重置

1. 登录需要重测的当前测试账号，点击“重置当前测试账号及全部本地数据”。无需管理员授权码输入，也无需日常服务器 CLI 操作。
2. App 在 AccountEngine 串行锁内检查当前账号/环境，查询 /me；仅明确访问令牌过期时走原有可恢复刷新流程。用当前 access Bearer 向 `/test-tools/v1/account-reset/prepare` POST `{}`。
3. 服务端仅从已鉴权会话确定目标，返回顶层预览字段和 15 分钟 grant。客户端要求目标 ID 等于本地当前账号；确认弹窗显示环境、账号、脱敏身份、关联游客和影响。
4. 确认后使用返回的短期 grant 和原 user_id/confirmation 调用 execute。普通 access token 不能执行重置。收到 reset=true、local_reset_required=true、目标一致的可验证成功后，立即调用 Android `clearApplicationUserData()`。系统结束应用，用户重新打开。
5. 系统拒绝清除时保留成功状态，提供“重试清除本地数据”。清除前再次检查原账号、origin 和 generation；账号/环境变更会阻止清除。

服务端应只允许测试数据库白名单，无 APK 管理密钥。工具请求走独立客户端，不写普通 API 日志，不存 access/grant/confirmation。当前配套后端 6052fe8 已通过 Jenkins #21 部署，SQL003 已执行且测试开关生效；复制新项目仍需单独配置测试库及开关。

执行响应未知、超时、取消或格式错误不会宣称成功，也不清除本地。保留同一 grant/confirmation，只允许重试原请求，锁住普通账号/环境操作，不重新 prepare。只有已知协议拒绝能证明未执行时才解锁新 prepare。原账号/环境/generation 校验和执行/清除共享 AccountEngine 串行锁；不会清错其他用户。

恢复材料只存 ViewModel 生命周期内存，未扩展秘密持久化。面板导航及使用同一 ViewModel 的 Activity 重建保留内存恢复状态，返回面板可继续；进程终止或 ViewModel 销毁会丢失材料；此时不能推断失败，需先在服务器核对执行状态再重新开始。未知状态下不通过本地清除逃避恢复。

## 仅清除本地

独立按钮另有确认，清除应用全部私有文件、noBackup 凭证、数据库、偏好、缓存、私有外部存储及未来启动/引导标记，并重置权限；应用结束后重新打开。不会重置服务端账号，不卸载 APK、不删除共享媒体、其他 App，也不撤销微信授权。现有工程没有新增自定义引导页。

## 设备验收（待执行）

- 取消两类确认均不改数据；准备和确认显示当前账号且没有授权码输入框。
- 成功响应后自动结束应用，重新打开无旧会话、缓存和引导标记，权限重新请求；其他 App/共享文件不变。
- 丢失 execute 响应只重试原授权；错误目标、环境或 generation 变更不清除本地。
- OS 拒绝清除后可重试；release 不包含工具实现且开关为 false。
- 仅专用可丢弃测试账号执行真实重置，验证旁观账号不变、旧会话失效、原身份可重新注册。

本次只进行本地构建与离线单元测试，未创建账号、未调用线上重置、未清除设备。

恢复补充：忙碌时允许展开开发工具以访问确认/恢复按钮，禁止收起。首次执行的明确协议拒绝可解锁；只要先前有未知结果，后续授权过期、工具关闭或其他拒绝都不能证明此前未执行，仍保留原授权/确认并禁止新 prepare 和本地清除，须先在服务端核实。
